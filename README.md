# 🏨 Hotel Booking Test Cases

This repository contains a collection of **manual test cases** designed for a **Hotel Room Booking Website**.  
The purpose of this project is to ensure the quality, reliability, and usability of the hotel booking platform.

---

## 📋 Project Overview
The test cases in this repository cover different aspects of the booking process, including:
- User registration & login
- Searching for available rooms
- Room selection & booking
- Payment process
- Booking confirmation & cancellation

---

## 🧪 Scope of Testing
1. **Functional Testing**
   - Validate core booking features (search, select, and confirm rooms).
   - Ensure accurate room availability and pricing details.
   - Verify booking duration (check-in / check-out dates).
   - Validate customer details during the booking process.
   - Verify payment gateway integration and booking confirmation.  
   ➡️ This type of testing focuses on the **core business functions** of the hotel booking system.

2. **Usability Testing**
   - Test ease of navigation across the booking website.
   - Validate clarity of form inputs (e.g., dates, number of guests, room type).
   - Check responsiveness of the interface on different devices (desktop/mobile).
   - Verify that error messages are clear, helpful, and user-friendly.  
   ➡️ This type of testing ensures a **smooth and user-friendly experience** for customers.

3. **Negative Testing**
   - Enter invalid inputs (e.g., incorrect dates, invalid payment details).
   - Attempt double booking for the same room and dates.
   - Try booking with incomplete customer information.
   - Test unsupported payment methods or expired credit cards.  
   ➡️ This type of testing focuses on **invalid or unexpected scenarios** and how the system responds.
